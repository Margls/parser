# DDN Transfer

Локальная панель для переноса публикаций с `ddnmgn.ru` на сайт в EISRF/Muzkult.

## Запуск

```powershell
npm.cmd install
npm.cmd run ui
```

Откройте `http://127.0.0.1:3000`, выполните вход в EISRF, вставьте ссылку на материал и нажмите «Перенести на новый сайт».

Кнопка запускает реальное создание новости. Для фотоальбома также создаётся галерея. Фотографии оптимизируются и загружаются в EISRF. Встроенные видео Rutube, YouTube и прямые ссылки на видео скачиваются в MP4 до 3 МБ, загружаются в текст новости и отображаются встроенным плеером.

Сессия входа хранится только локально в `.auth/`. Загруженные для переноса фотографии и видео находятся во временной системной папке и удаляются после завершения переноса — как успешного, так и неуспешного. JSON-файлы новостей, `transfers` и `previews` не создаются.
